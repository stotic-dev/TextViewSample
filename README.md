# TextViewSample
SwiftUIでUITextViewを扱うためのサンプルアプリです。
具体的な内容としては、簡単なチャットUIを表示するだけのアプリです。

## 仕様
1. 画面下部のテキストフィールドをタップすると、キーボードが表示され、テキストフィールドもキーボードに被らないように表示されます。
2. テキストフィールドの横にある送信アイコンボタンをタップすると、メッセージが表示されます。
3. メッセージを送信すると、Foundation Modelsによる応答メッセージが表示されます。
4. ナビゲーションツールバーの右上にあるゴミ箱アイコンボタンをタップすると、メッセージが全て消去されます。

## 技術スタック

言語：Swift 6.2
IDE：Xcode26.x
UIフレームワーク：UIKit、SwiftUI
アーキテクチャ：MV

### アーキテクチャの詳細
Model(M)-View(V)のアーキテクチャ

####Viewの役割
UIの表示と、UI操作によるイベントなどのプレゼンテーションロジックの制御
RepositoryはEnvironmentによりDIできるようにして、依存する。
Modelの依存の仕方は特に問わない


#### Modelの役割
ドメインロジックを持つ
UIの処理を含むプロセス外依存には一切依存せず、ModelはModel内の定義にしか依存しない。

Repository
プロセス外依存の処理を提供
protocolではなく、structとして定義して、RepositoryのAPIはstructのクロージャのプロパティとして定義する。
また原則的に特定のActorには依存しないAPIとする。
例外として、Repositoryないで扱うAPIがMainActorに依存している場合は、MainActorに依存させるようにする。
